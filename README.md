Want to become an AI engineer, but don't know what to learn first?

In this beginner-friendly roadmap, I share a 12-week plan based on real AI engineering work. You will build four projects: a news summarizer, a basic RAG app, a production AI agent, and a voice agent with LLMOps. Keep improving the same RAG app as you learn.

I am Shirin, an Engineering Manager in AI Engineering with 9+ years of experience building and deploying AI/ML applications.

YOU WILL LEARN HOW TO

- Use Python, GitHub, APIs, testing, and SQL
- Understand LLMs, tokens, embeddings, and fine-tuning
- Build RAG apps and add FastAPI
- Deploy with Docker, cloud services, and CI/CD
- Add agent memory, MCP, and LLMOps

Learning resources are free to access; some need a free account. APIs, cloud services, and compute can cost extra. Take more time if you are new to coding.
